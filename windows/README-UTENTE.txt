============================================
 ANONIMIZZATORE PDF
============================================

COSA FA
-------
Anonimizza automaticamente PDF rilevando e oscurando:
- Nomi di persona, email, telefoni, indirizzi
- Codici fiscali, P.IVA, carte d'identita', patenti, passaporti
- IBAN, carte di credito
- Termini specifici (nomi clienti, ragioni sociali, ecc.)

Supporta sia PDF testuali sia PDF scansionati (tramite OCR).
Tutto avviene in locale: i documenti non escono mai dal computer.


COME SI AVVIA
-------------
1. Doppio click sull'icona "Anonimizzatore PDF" sul Desktop
   (o dal Menu Start)
2. Si apre il browser su http://localhost:8501
3. Carica un PDF, configura cosa anonimizzare, premi "Anonimizza"
4. Scarica il PDF risultante


COME SI CHIUDE
--------------
Chiudi la finestra nera (CMD) che si e' aperta all'avvio.
La scheda del browser puoi chiuderla quando vuoi.


PROCEDURA CONSIGLIATA
---------------------
1. Carica il PDF
2. Lascia attivi i flag di default (sono gia' ottimizzati per
   documenti legali italiani)
3. Aggiungi nei "termini specifici" eventuali nomi, ragioni sociali
   o indirizzi che vuoi assolutamente oscurare
4. Clicca "Anonimizza documento"
5. VERIFICA SEMPRE il PDF risultante prima dell'invio


LIMITI
------
- L'AI puo' perdere nomi inusuali o oscurarne di sbagliati. Usa
  sempre i "termini specifici" per i nomi critici.
- PDF scansionati: l'OCR puo' perdere parole se la scansione e'
  di bassa qualita'.
- Documenti molto lunghi (>50 pagine) possono richiedere alcuni
  minuti, soprattutto se scansionati.


DISINSTALLAZIONE
----------------
Pannello di Controllo -> Programmi -> Anonimizzatore PDF
-> Disinstalla
